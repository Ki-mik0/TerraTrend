# Людський тест M3 «Пошуковик»

Ворота якості M3 (PLAN_ANALYTICS §11.4) рахуються **лише** на запитах, які написали люди.
Поки файлу `human_test.csv` немає, ворота мають статус `not_evaluated`, модель не вмикається,
а пошук працює на BM25.

`human_test.PLACEHOLDER.csv` — лише приклад формату. Код його ніколи не читає як тест.

## Що зібрати

- **~300 запитів**: щонайменше **100 українською** і **100 англійською** (менше — ворота
  лишаються `not_evaluated`). Краще 150 + 150.
- **Автори:** команда, учні, вчителі, знайомі науковці. Записуйте роль кожного автора.
- **Як просити.** Показати людині лише тему, а не назви змінних. Наприклад: «Ти хочеш
  дізнатися, чи стає в твоєму місті спекотніше. Що ти напишеш у пошук?»
  Не показуйте каталог і `lexicon.yaml`, інакше люди повторять наші формулювання.
- Пишіть як є, з одруківками, суржиком, скороченнями й назвами міст. Нічого не виправляйте.
- **Не можна:** генерувати запити LLM, брати їх з `lexicon.yaml` чи згенерованих пар,
  перефразовувати шаблони. Такі рядки зроблять ворота нечесними.
- Хто писав запити, не повинен редагувати `lexicon.yaml` після цього (щоб не «підігнати» тренування).

## Формат `human_test.csv` (UTF-8, кома як роздільник)

| колонка | що писати |
|---|---|
| `query` | запит дослівно, як його написала людина |
| `lang` | `uk` або `en` (мова запиту) |
| `relevant` | id змінних з `catalog/variables_starter.yaml`, що відповідають запиту, через `;`. Усі прийнятні відповіді, зазвичай 1–3 |
| `author_role` | `team`, `student`, `teacher`, `scientist` або `other` |
| `source` | завжди `human` |

Приклад:

```csv
query,lang,relevant,author_role,source
чи стає сухіше на півдні,uk,soil_moisture_surface;precipitation_imerg;precipitation_gpcp,student,human
is the ozone hole closing,en,total_ozone,teacher,human
```

## Розмітка `relevant`

Розмічати краще вдвох: один пише запит, інший (з каталогом) ставить `relevant`. Спірні
випадки вирішує третій. Якщо жодна змінна каталогу не підходить, рядок не додавайте, а
запишіть ідею змінної для каталогу окремо.

## Перевірка після заповнення

```bash
python -m earthtrend.analytics.training.varsearch evaluate <версія>
```

Команда перевіряє формат (невідомі id, `source` не `human`, мова), прибирає запити, що
збігаються зі згенерованими навчальними, і перераховує `metrics.json`, `gates.json` і картку
моделі. Модель вмикається тільки командою `promote` і тільки якщо ворота `pass`.
